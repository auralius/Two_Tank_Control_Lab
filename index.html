Controller API reference

Always available in student functions

state, params and memory are accessible in all your functions. They are bound automatically at each controller call. Do not redeclare them at the script top level.

Standard functions

init()
Optional. Runs once after each fresh reset; initialize memory here.
controller()
Required. Runs every params.dt. Return a numeric pump percent (0–100), or { pump: value }.

memory · writable student variables

memory starts as {}. Initialize counters, integrators, filters, and arrays inside init(). Only your code changes memory; it persists across controller calls and resets for each new experiment.

function init() {
  memory.sum = 0;
  memory.history = [];
}
// In controller():
memory.history.push(state.h2);

The simulator automatically updates both water levels; students only return pump commands and update their own memory. The command is saturated to 0–100%.

03 / EXPERIMENT SETUP

Change the hydraulic plant

A₁ ḣ₁ = qₚ − k₁₂√h₁   ·   A₂ ḣ₂ = k₁₂√h₁ − k₂√h₂ − d

Tₛ = 0.2 s · 260 s simulation duration

Changing the plant resets the experiment and memory.

Nonlinear dynamics and discretization

At each sample, the simulator holds the pump command constant and performs bounded explicit-Euler hydraulic updates with internal substeps ≤ 0.05 s. Negative volumes are prevented and excess water spills from full tanks.

q₁₂ = k₁₂√h₁   |   q₂ = k₂√h₂

Here d is an extra downstream leak (0.45 L/s after 115 s in the disturbance challenge). These are non-interacting tanks in series; the flow between them depends on Tank 1 level, not the level difference.
